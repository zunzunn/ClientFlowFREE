# 🚀 ClientFlow — Free Freelancer Toolkit

**ClientFlow** is a beginner-friendly, minimal SaaS-style web app designed to help freelancers manage clients, generate cold DMs, and create simple invoices — all in one place.

Built with simplicity and speed in mind, this is the perfect tool for freelancers who want to stay organized without using complex software.

---

## ✨ Features

### 💼 Client Tracker

* Add and manage clients easily
* Track status (Lead / Contacted / Closed)
* Add notes for each client
* Data saved locally (no login required)

---

### 💬 Cold DM Generator

* Generate ready-to-send cold messages
* Just enter your niche (e.g. gym, real estate)
* Perfect for outreach and getting clients

---

### 🧾 Invoice Generator

* Create simple invoices instantly
* Add client name, service, and amount
* Print or save as PDF

---

## ⚡ Tech Stack

* HTML
* Tailwind CSS
* Vanilla JavaScript
* LocalStorage (no backend)
